# Agent Steering Skill

This skill provides guidelines and operational boundaries for AI agents (like Claude or other LLM-based assistants) acting as developers on the Code Executor platform.

## Core Directives

When writing code or interacting with the sandbox environment, agents must adhere to the following steering rules:

### 1. Security & Sandboxing
- **Never attempt to bypass the sandbox:** The Code Executor runs inside a locked-down Docker container with no network access (`--network=none`). Do not try to download external files at runtime or open reverse shells.
- **Resource Limits:** Be mindful that executions have strict memory (256MB) and Timeout (max 120s) limitations. Code generated by the agent must be efficient.

### 2. Output Formatting & Logging
- **Standard Streams:** The Code Executor captures `stdout` and `stderr`. Agents must ensure that useful information for assertion/verification is printed to `stdout`. Do not rely solely on return values or file-system mutations.
- **Structured Error Handling:** When catching exceptions in Python, Go, Node.js, etc., print clear tracebacks to `stderr` to make API debugging easier.

### 3. Agentic Workflow (Self-Correction)
When the Code Executor API returns a status `failed` or `timeout`:
1. Analyze the `stderr` string.
2. Formulate a hypothesis for the failure (e.g., "Missing dependency", "Syntax Error").
3. Correct the `code` payload and resubmit to the `test-api` skill.

### 4. Dependency Management
- If a script requires a third-party package (e.g., `requests` for Python or `lodash` for Node.js), the agent must explicitly include it in the `dependencies` array of the `ExecutionRequest` payload.

## MCP Integration Prompt Injection
When an agent connects to the platform via the MCP (Model Context Protocol) server, here is the recommended system prompt steering:

```text
You are connected to the Code Executor Sandbox via MCP. 
You can execute arbitrary code in multiple languages (Python, Node.js, Go, Java, C#, Bash).
The sandbox has NO internet access. Do not write code that requires fetching external websites.
Use the execution tool iteratively: Write a small script, verify stdout, and then write the final implementation.
```
